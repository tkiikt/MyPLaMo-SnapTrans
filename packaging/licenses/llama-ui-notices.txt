llama.cpp b12121 Embedded WebUI (tools/ui) - Frontend Third-Party Notices
=========================================================================

The official prebuilt llama.cpp b12121 library (llama-server-impl) embeds 68
gzip-compressed static WebUI files (1 JS bundle, 1 CSS bundle with inline
KaTeX fonts, index.html, manifest.webmanifest, sw.js, workbox runtime, and
59 icon/splash image assets).

MyPLaMo SnapTrans launches llama-server with --no-webui, so these WebUI
assets are disabled and never served or executed at runtime. Because the
compressed bytes are still present inside the distributed llama-server-impl
binary, all bundled frontend dependencies, copyrights, NOTICE files, and
full official license texts are listed below.

Total bundled frontend components listed: 241
  - 237 npm packages (pinned versions from llama.cpp b12121 tools/ui/package-lock.json,
    including pdfjs-dist@5.4.54, katex@0.18.11, mermaid@11.17.2, highlight.js@11.11.1,
    dompurify@3.4.17, dexie@4.4.3, svelte@5.56.1, @sveltejs/kit@2.70.2, @lucide/svelte@1.46.0,
    workbox-*@7.4.1, Tailwind CSS / unified / remark / rehype / d3 / cytoscape, etc.)
  - 3 vendored JavaScript libraries from tools/ui/src/lib/vendors/
    (nerdamer-prime, decimal.js@10.6.0, big-integer)
  - KaTeX Fonts (12 font families embedded in CSS, SIL Open Font License 1.1)
  - Note: Build/test/lint-only devDependencies (eslint, prettier, vitest, playwright,
    storybook, typescript, svelte-check, vite, esbuild, rollup, @napi-rs/canvas, etc.)
    are not emitted into the browser bundle and are excluded.
